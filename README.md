# Mountaineering Website
- Continuous Assessment for the first semester of first year. Our objective was to create a website using only HTML and CSS.
- A live version can be found here: https://alexodwright.github.io/mountaineeringcoverpage
- The objective of this website is to showcase HTML and CSS while also displaying my love for mountaineering and the outdoors!
  - The website features a main page that contains information and images about some of the tallest mountains in the world.
  - The second page details mountains native to Ireland including Carrauntwohill, the highest mountain in the country!
  - The final page contains a gallery to showcase the beauty of mountains!
